# المعجم المهري (Mahra Dictionary)

مشروع المعجم المهري هو تطبيق ويب يهدف إلى توفير واجهة سهلة ومنظمة للوصول إلى مفردات اللغة المهرية وإدارتها.

## المميزات

- واجهة مستخدم عربية تدعم الاتجاه من اليمين إلى اليسار (RTL).
- تصميم بسيط ومتجاوب مع الهواتف وأجهزة الكمبيوتر.
- صفحة تسجيل دخول منظمة.
- هيكل مشروع قابل للتطوير.
- كود منظم وسهل الصيانة.

## هيكل المشروع

```text
mdict/
├── index.html
├── style.css
├── script.js
├── frontend/
│   ├── assets/
│   └── pages/
└── README.md
```

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (ES6)

## التشغيل

1. افتح ملف `index.html` في المتصفح.
2. أو انشر المشروع باستخدام GitHub Pages.

## الترخيص
